# Settle the specification gaps that block Phases 2, 3 and 5

## Intent

Amend `../SPEC.md` so the solver, connector and frame phases can be built without guessing. Each amendment is marked as an amendment with its date, and `../original-spec.md` stays untouched.

## Background

The spec review on 2026-11-13 found gaps that would produce wrong output in Phases 2, 3 and 5. The user answered four product questions the same day (decisions D1–D4 below). The remaining items (T1–T8) are technical defaults proposed during drafting. The user reviewed them the same day, supplied the reference image, changed T5 and T6, and agreed to the rest.

**Status: Approved by the user on 2026-11-13**, including the sequencing changes and the security statement.

Linear tickets: None.

### Decided by the user on 2026-11-13

- **D1 Connector shapes:** a connector tile sits just past the end of one name. The other, perpendicular name may either start or end next to the tile (L-corner) or run past it side-on (T-shape).
- **D2 Enclosed empty squares:** when names form a loop around empty squares, those squares are cut out as holes.
- **D3 Characters:** names may contain A–Z, apostrophe, hyphen and accented Latin letters. Letters are engraved uppercase. A space inside a name is rejected with a message suggesting the joined or hyphenated form.
- **D4 Default position:** the crossword is centred in the usable opening above the family-name region. A configurable minimum gap to the frame edge decides whether it fits.

### Technical defaults as approved

- **T1 Accented letters in detail:** text is Unicode-normalised (NFC) and uppercased. Each accented letter is one tile and intersects only an identical letter (É does not match E). A letter whose uppercase form is more than one character (ß) is rejected. An accented letter shows the point value of its base letter. A character the chosen font cannot draw is a validation error.
- **T2 Explicit connections in the data model:** `CrosswordLayout.connectors` is renamed `decorativeTiles`. Every decorative tile records the name end it extends (`anchor: { nameId, end: "start" | "end" }`). A connector also records the one other name it joins (`joinsNameId`). A connector joins exactly two names.
- **T3 Adjacency rule:** two squares that share an edge are legal only if both belong to the same name, or one is a decorative tile attached to the other's name through its anchor or join. The square before a name's first letter and after its last must be empty or a decorative tile anchored there. Squares touching only at a corner are allowed. A manual decoration may touch only the end of its own name.
- **T4 Solver stays pure:** the solver receives the usable opening as polygon data in tile units plus the minimum gap. It never loads fonts or draws. Until the frame exists (Phase 5), the opening is a plain circle.
- **T5 Position and fit in detail:** the centre of the crossword's bounding box is placed on the centroid of the usable opening; `offset` is added on top. `FrameSettings` gains `crosswordClearanceMm` (default 5, set by the user). The crossword fits when every tile lies inside the opening shrunk by that gap.
- **T6 Frame construction (revised to follow the reference image):** the frame layer's inner cut is the inner circle, closed at the bottom by a straight horizontal line at a configurable height. The user would prefer a curved bottom edge; the straight line is accepted for V1 and the curve is recorded as a later improvement. A close outline around the family name, offset by the buffer, rises above the line and merges into the solid area below; gaps between letters are bridged. The year sits below the line. The result must be one outer circle and exactly one inner opening.
- **T7 Library responsibilities:** `clipper2-ts` owns every union, difference and offset. `opentype.js` owns glyph outlines. Paper.js is not installed unless curve smoothing proves it is needed.
- **T8 Holes in the export:** inner hole cuts are part of the cut operation and are ordered before the outer perimeter, so the piece does not shift before its holes are cut. The phrase "only the outside perimeter is cut" in §2.1 is amended accordingly.

### Sequencing changes as approved

- Prototype the welded frame (Phase 5 geometry) directly after Phase 1, before the solver, because it is the highest-risk piece and independent of the solver.
- Import a throwaway SVG into LightBurn during Phase 4 rather than waiting for Phase 7.
