# Backer placement score mark

## Intent

The backer is a plain disk today, so once the crossword is cut out there is nothing on the backer showing where to glue it. Add a score mark to the backer that follows the crossword's shape, set slightly inside the crossword's cut lines so the glued piece covers it. The inset distance is a setting, 1 mm by default.

## Background

Mike is cutting physical pieces and needs a placement guide on the backer. The inset must be adjustable (for example 0.5, 1.5 or 2 mm) because the right amount depends on the material and kerf.

Linear tickets: None.

## Acceptance criteria

- AC1: `backer.svg` contains, in the score operation (score colour, "Score" group), a closed outline of the crossword offset into the crossword material by the inset distance, measured per side: every point of the mark is that distance from the cut line. A 5 mm x 3 mm rectangular crossword with a 1 mm inset gives a 3 mm x 1 mm mark.
- AC2: The mark is positioned on the backer exactly where the crossword sits inside the frame, so the backer cut circle and the mark share the same coordinates as `frame.svg` and `crossword.svg`.
- AC3: Holes in the crossword (enclosed empty squares) are marked too. Each hole mark is offset by the same distance into the material, so it is larger than the hole and hidden under the piece.
- AC4: The inset is a per-project setting, default 1 mm, editable in the Export step, saved with the project and restored on reopen, import and duplicate. Projects saved before this change open with 1 mm.
- AC5: The inset is validated like other numeric settings: a finite number within the allowed range (0.1 to 2 mm). An out-of-range value is rejected with a field message.
- AC6: Where the inset is too large for part of the shape (the inset outline collapses or splits), export does not produce broken geometry: the user gets a clear problem message instead of a silent wrong mark.
- AC7: The on-screen preview draws the mark on the backer under the existing "Score lines" layer, visible when the crossword layer is hidden.
- AC8: The proof image draws the mark on the backer, beneath the crossword.
- AC9: `crossword.svg` and `frame.svg` are byte-for-byte unchanged by this task.
- AC10: Unit tests cover the inset geometry (rectangle, L-shape, hole, changed inset value), the backer export, validation and the default for old projects. `README.md`, `docs/SPEC.md` (amendment) and the LightBurn import checklist describe the mark.

## Constraints / Architecture direction

- Perform implementation and validation in a dedicated task worktree. Preserve the user's original checkout and all existing local changes.
- Compute the mark in `src/core` from the existing crossword cut geometry (`cut.outer` and `cut.holes`), using the existing clipper-based helpers in `polygonOps.ts`. Corners stay square (mitred), not rounded.
- The setting lives in `ExportSettings` beside the operation colours and follows the same load, validate, default and save path.
- The backer export keeps its existing file name, colours and cut circle.
- No new dependencies.

## Security considerations

None. The change is geometry plus one numeric setting, which is validated (finite, in range) on load, import and save like the existing settings.

## Out of scope

- A placement mark for the frame ring (it already matches the backer's edge).
- Engraving or labelling on the backer.
- Any change to the crossword or frame pieces.
- A switch to turn the mark off.

## Open questions

None. Resolved on 2026-11-15: the inset is measured per side, and the range is 0.1 to 2 mm.
